# Embodied MuJoCo Learn

从手动示教到强化学习，探索机器人路径生成的多种方式。

# 一、项目简介

本项目在 MuJoCo 物理仿真环境中搭建了一个三自由度机械臂，通过四个递进的里程碑，逐步探索机器人路径生成的不同方法：

1. **手动键盘控制** ✅ 已完成
2. **示教轨迹记录与复现**
3. **逆运动学 + 轨迹规划**
4. **强化学习自动规划**

# 二、环境配置

## 1、前置要求

- Python 3.10+
- Windows / Linux / macOS


# 三、示例介绍

#### 1、手动键盘控制 ✅

通过键盘实时控制 MuJoCo 仿真环境中的三自由度机械臂，用末端红色小球触碰随机生成的绿色目标方块。

### a、运行方式

```bash
python scripts/01_manual_control.py
```

### b、操作说明

| 按键                 | 功能               |
| ------------------ | ---------------- |
| `←` / `→`          | 关节1（底座旋转）正转 / 反转 |
| `↑` / `↓`          | 关节2（大臂俯仰）正转 / 反转 |
| `Ctrl` + `↑` / `↓` | 关节3（小臂俯仰）正转 / 反转 |
| `空格`               | 所有关节复位到零位        |
| `ESC`              | 退出程序             |

### c、鼠标视角控制

| 操作   | 效果   |
| ---- | ---- |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |

### d、规则

1. 使用键盘控制机械臂，让末端红色小球靠近绿色目标方块。

2. 当末端与目标的距离小于阈值时，判定为**触碰成功**。

3. 触碰成功后：
   
   - 终端打印当前得分
   
   - 机械臂所有关节自动复位
   
   - 目标方块随机移动到工作空间内的新位置

4. 重复操作，累计得分。按 `ESC` 退出时显示最终得分。

### 机械臂结构

```
底座 (灰色圆柱)
    └── 连杆1 (蓝色) 5cm ── 关节1 (绕Z轴旋转)
         └── 连杆2 (橙色) 5cm ── 关节2 (绕Y轴俯仰)
             └── 连杆3 (绿色) 5cm ── 关节3 (绕Y轴俯仰)
                 └── 末端标记点 (红色小球)
```

### 技术要点

- **仿真引擎**：MuJoCo，通过 XML 定义机器人模型。

- **窗口交互**：GLFW，实现键盘按住连续控制和鼠标视角操作。

- **碰撞检测**：每帧计算末端 site 与目标 geom 的欧氏距离，低于阈值判定触碰。

- **目标移动**：触碰成功后，在机械臂工作空间内（球坐标系约束）随机生成新位置，确保始终可触及。

- **防重复计分**：通过连续接触帧计数器和状态锁，避免单次触碰被多次计分。

## 2、示教轨迹记录与复现 ✅

录制手动控制的关节状态序列，自动流畅复现，并按轨迹长度评分排行。

### a、运行方式

```bash
python scripts/02_mc_record_replay.py
```

### b、操作说明

| 按键                 | 功能                |
| ------------------ | ----------------- |
| `←` / `→`          | 关节1（底座旋转）正转 / 反转  |
| `↑` / `↓`          | 关节2（大臂俯仰）正转 / 反转  |
| `Ctrl` + `↑` / `↓` | 关节3（小臂俯仰）正转 / 反转  |
| `R`                | 开始录制（末端触碰目标时自动停止） |
| `P`                | 复现最近录制的轨迹（自动选最短）  |
| `空格`               | 所有关节复位到零位         |
| `ESC`              | 退出程序              |

### c、鼠标视角控制

| 操作   | 效果   |
| ---- | ---- |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |

### 功能说明

1. 按 `R` 开始录制，手动操作机械臂触碰固定位置的目标方块。

2. 触碰成功后自动停止录制，轨迹按时间戳保存至 `models/` 目录。

3. 按 `P` 打开轨迹排行榜，按状态点数量升序排列（越短得分越高），自动选择最优轨迹复现。

4. 复现时忽略录制中的停顿，以固定速度流畅回放。

### 技术要点

- **去重记录**：只在关节角度变化时记录新状态点，停顿不产生冗余数据。

- **评分排行**：按轨迹状态点数量归一化评分，鼓励用更短的路径完成任务。

- **流畅回放**：固定帧率逐帧切换，完全忽略原操作中的停顿时间。

## 3、逆运动学 + 轨迹规划 ✅

给定目标位置，机械臂通过逆运动学自动计算关节角度，并生成平滑轨迹。可一键对比手动示教与自动规划的差异。

### a、运行方式

```
python scripts/03_ik_planning.py
```

### b、操作说明

| 按键    | 功能                               |
| ----- | -------------------------------- |
| `空格`  | 随机生成目标，自动 IK 规划并执行               |
| `R`   | 完整对比流程（手动录制 → 演示手动轨迹 → 演示 IK 轨迹） |
| `ESC` | 退出程序                             |

### c、R 键完整流程

| 阶段  | 内容                    |
| --- | --------------------- |
| 1   | 目标设为固定位置，机械臂复位，手动操控触碰 |
| 2   | 触碰后自动回放刚才的手动轨迹        |
| 3   | 自动计算 IK 并演示规划轨迹       |
| 结束  | 终端打印最终距离，直观对比两种方法     |

### ### 技术要点

- **数值逆运动学**：基于阻尼最小二乘法的雅可比伪逆求解，迭代优化关节角度。

- **多段路径规划**：在笛卡尔空间取多个中间路径点，分别求解 IK 后在关节空间平滑插值，避免穿模。

- **Smoothstep 缓动**：轨迹插值使用 smoothstep 曲线，运动更加平滑自然。
