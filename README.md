# Embodied MuJoCo Learn

从手动示教到强化学习，探索机器人路径生成的多种方式。

# 一、项目简介

本项目在 MuJoCo 物理仿真环境中搭建了一个三自由度机械臂，通过四个递进的里程碑，逐步探索机器人路径生成的不同方法：

1. **手动键盘控制** ✅ 已完成
2. **示教轨迹记录与复现**
3. **逆运动学 + 轨迹规划**
4. **强化学习自动规划**

# 二、环境配置

## 1、前置要求

- Python 3.10+
- Windows / Linux / macOS

## 2、安装步骤

### （1）. 克隆仓库

```
git clone https://github.com/Echo-Ring/embodied-mujoco-learn.git
cd embodied-mujoco-learn
```

### （2）. 创建虚拟环境（推荐）

```
conda create -n embodied python=3.10 -y
conda activate embodied
```

### （3）. 安装依赖

```
pip install -r requirements.txt
```

# 三、示例介绍

#### 1、手动键盘控制 ✅

通过键盘实时控制 MuJoCo 仿真环境中的三自由度机械臂，用末端红色小球触碰随机生成的绿色目标方块。

### a、运行方式

```bash
python scripts/01_manual_control.py
```

### b、操作说明

| 按键                 | 功能               |
| ------------------ | ---------------- |
| `←` / `→`          | 关节1（底座旋转）正转 / 反转 |
| `↑` / `↓`          | 关节2（大臂俯仰）正转 / 反转 |
| `Ctrl` + `↑` / `↓` | 关节3（小臂俯仰）正转 / 反转 |
| `空格`               | 所有关节复位到零位        |
| `ESC`              | 退出程序             |

### c、鼠标视角控制

| 操作   | 效果   |
| ---- | ---- |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |

### d、游戏规则

1. 使用键盘控制机械臂，让末端红色小球靠近绿色目标方块。

2. 当末端与目标的距离小于阈值时，判定为**触碰成功**。

3. 触碰成功后：
   
   - 终端打印当前得分
   
   - 机械臂所有关节自动复位
   
   - 目标方块随机移动到工作空间内的新位置

4. 重复操作，累计得分。按 `ESC` 退出时显示最终得分。

### 机械臂结构

```
底座 (灰色圆柱)
    └── 连杆1 (蓝色) 5cm ── 关节1 (绕Z轴旋转)
         └── 连杆2 (橙色) 5cm ── 关节2 (绕Y轴俯仰)
             └── 连杆3 (绿色) 5cm ── 关节3 (绕Y轴俯仰)
                 └── 末端标记点 (红色小球)
```





### 技术要点

- **仿真引擎**：MuJoCo，通过 XML 定义机器人模型。

- **窗口交互**：GLFW，实现键盘按住连续控制和鼠标视角操作。

- **碰撞检测**：每帧计算末端 site 与目标 geom 的欧氏距离，低于阈值判定触碰。

- **目标移动**：触碰成功后，在机械臂工作空间内（球坐标系约束）随机生成新位置，确保始终可触及。

- **防重复计分**：通过连续接触帧计数器和状态锁，避免单次触碰被多次计分。
